# Phế Liệu Thiên Nhung

Website quản lý thu mua phế liệu gồm trang công khai, khu vực admin và cổng customer. Frontend dùng React/Vinext, backend dùng Node.js và PostgreSQL.

Admin quản lý khách hàng, vật liệu, bảng giá, đơn hàng, tồn kho, hóa đơn và báo cáo. Customer đăng ký bằng số điện thoại, đăng nhập và chỉ xem được lịch sử giao dịch, hóa đơn và báo cáo của chính mình.

Hệ thống có authentication, RBAC admin/customer, session cookie, CSRF/CORS protection, validation, transaction PostgreSQL, inventory movement, audit log và kiểm thử với PostgreSQL thật.
